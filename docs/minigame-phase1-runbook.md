# 《大明浮生记》微信小游戏第一阶段 - 运行与开发手册

## 一、 项目定位与环境准备

本项目为《大明浮生记》纯单机、离线本地存档的微信小游戏。无需任何后端服务或外部网络连接即可直接在微信开发者工具或真机中运行。

### 依赖环境
- Node.js >= 16.x (用于资源生成与自动化测试脚本)
- 微信开发者工具 (推荐最新稳定版)

---

## 二、 快速运行与验证指南

### 1. 微信开发者工具导入与运行
1. 打开**微信开发者工具**。
2. 选择 **“小程序/小游戏”** -> **“导入项目”**。
3. 项目目录选择本项目根目录：`c:\Users\Administrator\WeChatProjects\minigame-1`。
4. AppID 可以选择 **“测试号 (体验)”** 或已有的小游戏 AppID。
5. 后端服务选择 **“不使用云服务”**。
6. 点击打开，即可直接在模拟器中看到横屏 960×640 居中运行的创角界面！

---

## 三、 工具链与自动化构建命令

### 1. 重新生成第一阶段依赖资源
如果修改了 XML 或原始配置，可运行：
```bash
node tools/minigame-assets/generate-phase1-assets.js
```
该命令会自动将 `CreateRole.xml` 和 `ui.ani` 转换为 JSON 描述，并提取 1.79MB 最小依赖闭包至 `minigame_assets/`。

### 2. 执行自动化验收测试套件
```bash
node tools/minigame-assets/verify-phase1.js
```
自动化检查：
- 微信小游戏主包配置与入口合法性
- 资源注册表唯一性与 100% 存在性
- UI 控件尺寸与层级规范
- 创角逻辑（性别切换、随机姓名、空姓名拦截校验）
- 本地存档（v1 结构、写入、持久化恢复、损坏容错、重置清除）

---

## 四、 核心玩法与测试流程

1. **首次进入**：无本地存档时，游戏自动进入创角页。
2. **选择性别**：点击左侧男性立绘或“我是帅哥”切换为男主角；点击右侧女性立绘或“我是美女”切换为女主角。选中的角色立绘周围会有金黄色发光选择框。
3. **随机取名**：点击“随便起名”，系统自动从百家姓与常用汉字库组合生成武侠古风名字。
4. **手动输入**：点击输入框可唤起输入法修改姓名，支持 1-10 个字符限制。
5. **开始游戏**：点击“开始游戏”，完成校验后生成本地持久化存档（Key: `daming_minigame_single_save`），并进入角色展示页面。
6. **重启恢复**：在微信开发者工具中点击“刷新/重启”小游戏，小游戏检测到已有存档，会自动恢复已创建的角色并直接展示，验证持久化有效性。
7. **重置测试**：在角色展示界面点击“重置并重新创角”，将清空本地测试存档并重新进入创角页。

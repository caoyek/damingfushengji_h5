# 《大明浮生记》H5 网页端工程规范与资产指南 (Web SPA)

> **技术定位**：纯原生现代 HTML5 / JavaScript / Canvas 单页应用 (SPA)。  
> **核心优势**：零编译打包、零第三方依赖，任意现代电脑或手机浏览器双击即可开玩。

---

## 一、 目录架构与规划

```text
web/
├── index.html                 # 游戏主页面入口 (包含古风宣纸外衬响应式容器)
├── README.md                  # 本文档
├── css/
│   └── style.css              # 页面视口居中样式与古风水墨边框滤镜
├── js/
│   ├── main.js                # 网页启动入口与事件循环引导
│   ├── engine/                # 游戏渲染引擎 (与 minigame 共享的 Canvas 绘制算法)
│   ├── battle/                # 战斗演算与伤害公式 (直接复用 GDD-02 算法)
│   └── network/               # 网络请求适配器 (对接 ../server/ 或 LocalStorage 离线存储)
└── assets/                    # 网页所需的精选切图与音频资源
```

---

## 二、 关键技术细节

1. **Web Audio 自动播放拦截破解**：
   * 现代 Chrome/Safari 默认静音策略：在玩家未与页面交互前禁止自动播放 BGM。
   * 处理准则：首次在页面点击“开始游戏”或任意按钮的瞬时，调用 `AudioContext.resume()` 激活音频驱动池。
2. **全屏响应式居中**：
   * 使用 CSS Flex 布局将 960×640 的 Canvas 永远保持等比居中；
   * 外围铺满宣纸水墨底纹，在 4K 宽屏显示器上视觉效果极佳。
3. **数据本地化与多模式运行**：
   * **纯离线单机模式**：所有进度自动序列化为 JSON 写入 `window.localStorage`，换设备可手动导出存档文本；
   * **多人联机模式**：通过 Fetch API 向 `http://127.0.0.1:8080/index.php` 发起标准 POST 请求。

## 三、 本地快速启动

进入 `web/` 目录，执行轻量静态服务命令：

```bash
# Python 3 静态服务
python -m http.server 8080
```

随后在浏览器中访问：`http://127.0.0.1:8080`

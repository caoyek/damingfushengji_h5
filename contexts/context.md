# 《大明浮生记》现代化复刻工程核心上下文 (Project Core Context)

> 本文件为遵循【中文原生协议 v5.0】维护的项目核心上下文档案。记录项目背景、底层逆向铁证、设计规范体系与落地工程路线。

---

## 一、 项目定位与核心愿景

- **项目名称**：《大明浮生记》多端现代化复刻与全量资产档案工程 (Daming Fushengji Remaster)
- **原始出处**：福建网龙（NetDragon）自主研发的 C3 引擎经典国产水墨恶搞武侠网页/手机网游。
- **重构目标**：
  - 以现代化技术栈（Canvas/Web/Node.js/微信小游戏/Android单机化壳）对全量原版资产与数值玩法进行 100% 忠实还原。
  - **最高工程铁律**：严禁无凭据的硬编码与臆想。所有系统、界面坐标、协议字段、数值公式必须 100% 对齐真机底层动态库 `libEnvRelay.so`、客户端 348 个 XML 布局、官方 31 张配置数据表及 2296 条语言字典。

## 二、 核心底层资产与逆向事实

1. **视听与表现资产** (`extracted_full_resources/client_assets/`)
   - **10,213 张切图 (PNG)**：洛阳、南京等 15 府全景大地图、NPC/武将立绘、怪物切图、宣纸边框 UI。
   - **348 个 XML 布局文件**：界面控件绝对坐标、层级、锚点。
   - **53 首音频 (OGG)**：战斗、过关、城池、升级、技能音效。
   - **1 套原版楷体矢量字库 (TTF)**。

2. **配置数据底表** (`extracted_full_resources/server_data/`)
   - `CreateRoleInfo.csv`：起名库（292 姓氏 + 348 名字）。
   - `BattlePos.csv`：战斗九宫格站位像素坐标（攻守双方各 9 个坐标点）。
   - `BattleSetting.csv`：战斗时序参数（入场 300ms、攻击 800ms、击退 400ms、震屏 60ms、淡出 1000ms）。
   - `SkillAction.csv` / `ArmyAction.csv`：招式与动作映射表。
   - `RookieGuideInfo.csv`：新手村至过关通道前 150 步剧本与奖励。
   - `ProfessionName.csv`：四大门派定义（1000 混混、1001 攻将、1002 防将、1003 阉派）。
   - `BagComboList.csv`：9 大装备等级跨度阶梯（1-10 到 81-99）。

3. **底层动态库 `libEnvRelay.so` 核心结论**
   - **50 个 CMsg 核心网络协议**：涵盖创角、移动、战斗、打工、强化、经脉、商店、聊天等。
   - **主界面与基础外壳**：`CDlgShell` (1732B)、`CPnlShellUser` (1720B)；底栏固定 6 大入口（角色、强化、技能、背包、任务、其他）。
   - **角色 10 大属性与 6+1 槽位**：生命、内力、物攻、魔攻、物防、魔防、速度、命中、闪避、暴击；头盔/铠甲/主手/副手/腰带/战靴 + 恶搞【脸皮】。
   - **双轨制技能体系与 3 技能限制**：主动战斗技能（每人严格限选 3 个装配出战，战时根据 MP 释放）+ 被动强身技能（加十维属性），战功升级，洗点 100% 全额返还。已从 `skill.ani` 完整提取出四大门派 34 种官方技能谱系。
   - **战斗系统架构（服务端权威演算 + 前端纯播放）**：
     - `CBattle::ProcessBattleInfo`（0x00535B0C）证实：所有伤害、先后手（速度倒序）、怪物反击与胜负由服务端瞬时完成推演，下发 `rounds` JSON 战报；
     - 客户端 SO / 前端仅作为动画与音效播放器，支持 VIP 跳过战斗；
     - 服务端推演器（`CombatSimulator`）由我们在 `server/` 与本地虚拟引擎中双模自主实现，怪物属性表（`dungeon_monsters.json`）与玩家角色 100% 同构。
   - **装备系统驱动机制**：客户端本地无静态装备数值表，服务端动态下发 JSON。
     - 统一协议字段：`item_id`, `item_name`, `level`, `wuzhong_limit`, `shuxing_att`, `shuxing_def`, `howmuch`, `is_baifenbi`, `up_base`, `weapon_effect`, `price`。
     - 强化成长计算公式：$$\text{实时属性} = \text{howmuch} + \text{强化等级} \times \text{up\_base}$$。
     - 四大获取途径：铁匠铺打造（二星钻石/水晶/玛瑙）、常规商店（铜钱买白绿）、神秘黑市（战功换极品）、主线推进赠送。

## 四、 阶段推进策略与当前状态

### 4.1 核心策略：聚焦基础，分步落地
- 严控复杂度：当前阶段暂不引入夫妻双修、城主争霸、大姨妈世界BOSS等外围庞杂玩法。
- 严格遵循真实游戏进度推进。

### 4.2 第一阶段（Phase 1）目标与范围
- **目标**：从零启动游戏 -> 创角起名 -> 广州城二婶子对话领取一星晾衣杆 -> 换装穿戴 -> 学习提升技能 -> 出城进入过关通道打通前三场战斗（1-1 流氓、1-2 恶霸、1-3 地痞）-> 结算奖励。
- **详细落地规范**：参见 `docs/phase1_playable_development_plan.md`。

## 五、 代码开发规范与原则

1. **中文原生原则**：说明、注释、规划与 Git 提交信息一律使用中文；
2. **零臆测原则**：所有配置表字段与类名严格使用已解析的真实标识符；
3. **分层清晰**：核心战斗与数值引擎（`CoreEngine`）与视图渲染层（Canvas/DOM/UI）解耦，便于跨端共享。

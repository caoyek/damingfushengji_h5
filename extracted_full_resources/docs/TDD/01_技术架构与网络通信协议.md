# TDD-01: 技术架构与网络通信协议规范

## 1. 总体架构
* **前端引擎**：天晴 C3 引擎 (C++ `libEnvRelay.so`)
* **协议格式**：基于 JSON 的消息通信，前端由 `CMsg*::ProcessJsonEvent(eventId, jsonValue)` 处理。
* **路由定义**：
  * HTTP POST `/index.php`（登录、验证、充值、版本检测）
  * Socket 端口 `8008`（长连接战斗交互、聊天、实时通知）

## 2. 核心通信模块 (CMsg 接口对照)
* `CMsgLogin`: 登录认证、区服列表获取
* `CMsgRole`: 角色创建、基础属性拉取
* `CMsgBattle`: 副本推图 `SendFightRoad`、打怪 `SendMonsterId`、擂台 `SendLeiTaiMemberId`
* `CMsgAttrCulture`: 属性洗练与洗髓培养
* `CMsgEquipStrengthen`: 装备强化与精炼
* `CMsgEquipTrans`: 装备强化等级转移
* `CMsgPrison`: 大牢互动、家丁打工、抓捕与越狱
* `CMsgFair`: 倒卖场商品买卖与价格拉取
* `CMsgExam`: 科举答题与官职俸禄
* `CMsgTongji`: 江湖通缉令发布与缉拿

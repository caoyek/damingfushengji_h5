# GDD-02: 战斗机制与数值公式设计规范

## 1. 战斗时序与阵位 (Battle Timings & Positions)
* **时序参数 (参考 `BattleSetting.fdb`)**：
  * 入场移动：300ms
  * 攻击移动总耗时：800ms
  * 基础动作帧间隔：30ms
  * 受击击退：400ms / 10px
  * 暴击震屏：60ms / 15帧
  * 死亡淡出：1000ms (闪烁3次)
  * 胜利结算：500ms / 失败结算：1000ms
* **阵型矩阵 (参考 `BattlePos.fdb`)**：
  * 双方各有 6 个站位（前排上中下、后排上中下），支持最多 6v6 回合制对战。

## 2. 核心判定公式 (Formulas)
* **速度先手**：每回合按全场角色 `Speed` 从大到小排列行动顺序。
* **命中判定**：`命中概率 = max(10%, min(100%, 95% + (攻方Hit - 守方Dodge) / 等级系数))`
* **格挡判定**：触发格挡后，`最终伤害 = 理论伤害 * 50%`。
* **暴击判定**：`暴击概率 = max(5%, min(100%, (攻方Crit - 守方Toughness) / 等级系数))`，暴击伤害为基础伤害的 150%。
* **伤害公式**：`最终伤害 = (攻方攻击 * 技能倍率 - 守方防御 * 防御抵扣系数) * (1 - 减伤率)`

> 📌 **架构与工程定位**：  
> 底层逆向实证表明，网龙原版手游的伤害公式闭源运行于服务端，客户端 `libEnvRelay.so`（`CBattle::ProcessBattleInfo`）仅作为纯回放渲染器。  
> 本文公式作为单机模式下的**本地通用演算引擎规范**，用于在脱机状态下驱动真实攻防扣血与胜负判定，演算结果输出为与官方原版 100% 兼容的战报 JSON 数据流。详见 [docs/libEnvRelay_so_protocol_specification.md](../../../docs/libEnvRelay_so_protocol_specification.md#35-单机模式与服务端模式下的战斗工程落地)。

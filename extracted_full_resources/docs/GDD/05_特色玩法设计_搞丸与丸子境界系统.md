# GDD-05: 特色玩法设计 - 搞丸与丸子境界系统 (MakeBall System)

## 1. 系统概述
“搞丸（MakeBall）”系统是《大明浮生记》极具代表性的特色属性养成与道具产出玩法。
玩家通过在搞丸房“搓丸子”，产出各种品质的经验丸、属性丸、垃圾丸与丸子碎片，装备于角色或武将身上大幅提升战力。

## 2. 核心架构与模块划分
* **搞丸主界面 (`CDlgMakeBall`)**：点击消耗银两/材料搓丸子。
* **搞丸境界 (`CDlgMakeBallLevel`)**：包含 6 大搞丸地宫，提升境界可大幅提高出极品丸子的概率。
* **丸子仓库 (`CDlgBallStore` / `BallStoreItem.xml`)**：存储、整理和一键吞噬丸子。
* **丸子装备与拖拽 (`CDlgBallDrag`)**：将丸子拖拽穿戴到角色/武将孔位上。
* **丸子兑换所 (`CDlgBallExchange` / `BallExchangeItem.xml`)**：使用垃圾丸分解的“丸子碎片”保底兑换极品神丸。

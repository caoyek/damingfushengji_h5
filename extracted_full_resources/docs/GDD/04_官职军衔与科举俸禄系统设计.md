# GDD-04: 官职军衔与科举俸禄系统设计规范 (Officer Rank & Imperial Examination)

## 1. 系统概述
官职军衔与科举系统是《大明浮生记》展现大明朝廷仕途升迁、官职俸禄与全队属性加成的核心社会体系。  
玩家通过参与每日科举考试（乡试、会试、殿试）答题考取功名，从九品芝麻官逐阶晋升至一品大员乃至内阁首辅，每日领取高额朝廷俸禄并为全队武将提供战力光环。

## 3. 科举答题考试玩法与作弊机制 (Imperial Examination)

### 3.1 考试流程
1. **每日考题**：每日 00:00 刷新 10 道古代历史文化常识选择题；
2. **全对状元**：10 题全对直接触发 `ExamAllRightResult.xml`，获得“昨日状元之星”称号并在主界面展示；
3. **作弊系统 (`ExamZuobi.xml`)**：
   * 遇到难题时，玩家可消耗银两使用“小抄”，直接排除一个错误选项；
   * 可消耗元宝使用“买通考官”，直接获取正确答案；
   * 可点击“求助同门”触发 `ExamWantRightNotify.xml` 向帮派/好友求助答案；
4. **VIP 免试特权 (`ExamVip.xml` / `ExamVipResult.xml`)**：
   * 高阶 VIP 玩家可直接一键免试满分通过。

## 4. 界面排版与底层 C++ 映射
* **主考界面**：`client_assets/ui_layouts/ExamMgr.xml`
* **发榜奖励**：`client_assets/ui_layouts/ExamAward.xml`、`ExamResult.xml`
* **作弊弹窗**：`client_assets/ui_layouts/ExamZuobi.xml`
* **底层通信协议**：`CMsgExam`（`SendExamAnswer`, `SendGetAward`, `SendZuobi`）
* **俸禄领取**：`CMsgRole::SendGetSalary`，每日限领一次，跨天重置。

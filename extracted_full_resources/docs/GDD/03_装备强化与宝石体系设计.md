# GDD-03: 装备强化与宝石体系设计规范

## 1. 装备构成与等级段
* **部位**：武器、头盔、衣服、护腕、腰带、鞋子（共 466 款贴图）。
* **等级段 (10阶)**：1-10级、11-20级、21-30级、31-40级、41-50级、51-60级、61-70级、71-80级、81-90级、91-99级。
* **品质等级 (5阶)**：白色(0) -> 绿色(1) -> 蓝色(2) -> 红色(3) -> 紫色(4)。

## 2. 强化与继承规则
* **强化保底**：强化前 10 级成功率为 100%。
* **装备传承 (EquipTran)**：低级强化装备可无损/低损转移至高级装备。
* **宝石系统 (1~10品)**：物攻石、法攻石、物防石、法防石、生命石、暴击石、速度石。

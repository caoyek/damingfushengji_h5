## 一、系统架构定性：服务端动态驱动机制

### 1.1 核心反编译事实
在 `libEnvRelay.so` 底层机器码中，客户端并没有预置一张包含千百件具体装备的本地静态大表，而是由服务端数据库完全驱动，通过标准 JSON 协议在玩家打开商店、铁匠铺、背包或完成任务时动态下发：
* **`CItemMgr::ParseAct` (偏移 `0x00625748`)**：核心属性解释器；
* **`CCraftShop::ReceiveCraftShopData` (偏移 `0x0065fd2c`)**：铁匠铺打造配方接收器；
* **`CEquipShop::ReviceEquipInfo` (偏移 `0x005ea68c`)**：装备商店数据接收器。

### 1.2 官方正统装备协议字段规范 (JSON Data Contract)
服务端与客户端通信的每一件装备，必须且仅能使用以下经过逆向验证的原生键名：
```json
{
  "item_id": 1002,
  "item_name": "一星晾衣杆",
  "level": 1,
  "wuzhong_limit": 1000,
  "shuxing_att": 15,
  "shuxing_def": 0,
  "howmuch": 15,
  "is_baifenbi": 0,
  "up_base": 5,
  "weapon_effect": "二婶子赠送的祖传晾衣杆，市井混混防身必备",
  "price": 100
}
```
* **`item_id`**：装备全局唯一模版 ID；
* **`item_name`**：装备显示名称；
* **`level`**：佩戴需求等级；
* **`wuzhong_limit`**：职业门派限制（1000:混混, 1001:攻将, 1002:防将, 1003:阉派）；
* **`shuxing_att` / `shuxing_def`**：主属性类型标识（攻击 / 防御）；
* **`howmuch`**：主属性增加的基础数值；
* **`is_baifenbi`**：数值类型（0: 固定数值，1: 百分比加成）；
* **`up_base`**：**强化成长底数**（每提升 1 星强化等级，主属性增加的绝对固定值）；
* **`weapon_effect`**：富文本描述与附加特效；
* **`price`**：基础银两售价。

## 二、角色装备槽位与分类规格

### 2.1 角色“6+1”装备槽位体系 (`RoleInfo.xml`)
玩家与上阵武将均拥有 6 个正式装备槽位与 1 个恶搞防御槽位：
1. **头部 (`ImgHead`)**：头盔、儒冠、道巾、铁盔（默认占位字图 `image_word37`）；
2. **身体 (`ImgBody`)**：铠甲、布衣、长袍、法袍（默认占位字图 `image_word36`）；
3. **主手武器 (`ImgRightHand`)**：刀、剑、枪、杖、棍（默认占位字图 `image_word39`）；
4. **副手法器 (`ImgLeftHand`)**：盾牌、护手、折扇、法珠（默认占位字图 `image_word34`）；
5. **腰部佩饰 (`ImgWaist`)**：腰带、玉佩、束带（默认占位字图 `image_word38`）；
6. **鞋子轻履 (`ImgFoot`)**：战靴、草鞋、布靴、皮靴（默认占位字图 `image_word35`）；
7. **恶搞槽位【脸皮】(`ImgBrazenFace`)**：位于头部上方，对应市井混混“增厚脸皮”的专属防御槽（`361401`、`361404`），通过挨揍暴击增厚层数提升免伤。

### 2.2 官方 9 大等级跨度标准 (`BagComboList.csv`)
官方将游戏全生命周期划分为 9 大装备阶梯，各府城池严格对齐：
* **1-10级**：新手村 / 广州段
* **11-20级**：福州段
* **21-30级**：成都段
* **31-40级**：宁波段
* **41-50级**：南京段
* **51-60级**：武汉段
* **61-70级**：西安段
* **71-80级**：大同段
* **81-99级**：北京紫禁城段

### 2.3 官方 5 阶品质色码与成长倍率
底核函数 `CXmlString::GetDwColorByQuality`（地址 `0x007405EC`）写死的 5 阶标准：
| 品质阶数 | 官方品质名称 | 底层 ARGB 颜色码 | 基础属性成长倍率 |
| :--- | :--- | :--- | :--- |
| **0 阶** | **凡品 (白/灰)** | `#FFFFFF` / `#000000` | **1.0x** (基准) |
| **1 阶** | **良品 (绿)** | `#009C48` | **1.2x** |
| **2 阶** | **名品 (蓝)** | `#0166FF` | **1.5x** |
| **3 阶** | **神品 (红)** | `#DE1E1E` | **2.0x** |
| **4 阶** | **至尊 (紫)** | `#EE82EE` / `#BB51DA` | **3.0x** |

## 三、四大装备系统级获取途径

### 3.1 核心途径一：铁匠打造合成铺 (`CCraftShop` / `CraftShop.xml`)
获取二星及以上、名品/神品/至尊神装的最核心途径：
1. **打造规则与材料三巨头**（官方台词 `400368`）：
   > **“在这里可以用二星钻石、二星水晶、二星玛瑙合成二星品质的装备。也可以将低级宝石合成高级宝石、将低品质宝石合成高品质宝石。”**
2. **材料产出闭环**（`361316`）：
   - **钻石**：挑战各府城外【过关通道】副本掉落；
   - **水晶**：各府城外【采集点】采集特产掉落；
   - **玛瑙**：各府城外【野怪中心】刷怪挂机掉落；
3. **打造操作**：
   - 银两打造 (`btnWithGold`)：消耗对应钻石/水晶/玛瑙与少量铜钱；
   - 元宝一键打造 (`btnWithYuanBao`)：若材料不足，按材料缺口折算元宝直接补齐；
   - 批量全部打造 (`btnWithGoldAll`)。

### 3.2 基础途径二：常规装备商店 (`CEquipShop` / `EquipShop.xml`)
* 供玩家在各主城直接消耗铜钱购买 1-10 级、11-20 级基础白绿过渡装备；
* 支持按四大职业（`StaSuitJob`）和需求等级（`StaNeedLV`）快速检索。

### 3.3 极品途径三：神秘黑市商店 (`MysteriousStore.xml` / `AutoRefreshSecretShop.xml`)
* 神秘商人掌柜 (`image_npc19`)；
* **战功直接兑换** (`Sta_BattleCost`)：除铜钱外，支持消耗日常与PK积攒的“战功”直接兑换成件神装与高品宝石；
* 支持每日免费刷新 (`Sta_RefreshTimes`)、元宝即时刷新 (`btn_RefreshNow`) 与自动连抽过滤极品 (`btn_AutoRefresh`)。

### 3.4 任务途径四：主线推进阶段性奖励 (`RookieGuideInfo.csv`)
* **第 4 步 (新手起步)**：二婶子赠送第一把武器——【一星晾衣杆】(ID: `1002`)；
* **第 150 步 (跨城突破)**：直接空投奖励至尊紫色防具——【黄族腰带】；
* **第 152 步 (合成引导)**：直接空投【三级蓝水晶】+【三级蓝玛瑙】+【三级蓝钻石】，引导进入铁匠铺体验合成。

## 四、装备强化、传承与宝石镶嵌

### 4.1 装备强化体系 (`CDlgEquipStrengthen` / `EquipStrengthen.xml`)
1. **强化机制**：
   - 消耗银两与强化石，强化等级每升 1 级，直接给装备增加固定 `up_base` 属性值；
   - 前 10 级强化成功率极高，高阶强化成功率随星级递减。
2. **装备传承 (`EquipTran.xml` / `EquipTranAttrInfo.xml`)**：
   - 解决玩家频繁换装的痛点：低等级高强化装备，可将强化星级与附加属性一键无损/低损转移到同部位的高级新装备上，仅消耗少量银两。

### 4.2 宝石镶嵌体系 (1~10品)
* 每件装备最高开放 4 个宝石孔位；
* 镶嵌宝石类型：物攻石、法攻石、物防石、法防石、气血石、暴击石、速度石；
* 低品宝石采用 3 合 1 规则进阶合成高品宝石。

## 五、第一阶段 (Phase 1) 实施与数据配置指引

针对第一阶段微信小游戏可玩版本，由于服务端机房数据已随历史服务器关闭，我们在服务端数据库建设中必须遵循以下工程标准进行补齐：
1. **数据表位置**：在 `server/` 端建立 `equip_template` 配置库；
2. **阶段范围**：优先完整配置 **1~10 级新手村至第一座大城阶段的基础装备集**（涵盖 6 大部位各职业基础装备，如【一星晾衣杆】、轻铁剑、粗布麻衣、粗麻腰带、草鞋等）；
3. **数据格式严格对齐**：必须包含 `item_id`, `item_name`, `level`, `wuzhong_limit`, `shuxing_att`, `shuxing_def`, `howmuch`, `is_baifenbi`, `up_base`, `weapon_effect`, `price`，确保客户端与底层 SO 逻辑无缝吞吐解析。

## 一、 职业体系架构：单一起点与 20 级转职分流

《大明浮生记》并非创角即自选四大门派，而是采用了**“市井混混起步 -> 历练升级 -> 进城转职成为正规门派”**的经典江湖逆袭叙事。

### 1.1 初始全员职业：混混 (ID: 1000)
* **设定背景**：朱家流落民间的皇二代，起步于广州市井，身穿粗布衣、手持晾衣杆的街头混混；
* **职业代号**：`1000`（官方 `ProfessionName.csv`）；
* **基础特征**：身法敏捷、滑不留手。专属核心被动技能为恶搞神技**【厚脸皮】**（通过挨揍暴击增厚免伤层数）与初阶爆发技**【暗界波】**。

## 三、 全量技能体系架构：双轨制机制 (`CDlgSkill` / `Skill.xml`)

游戏中的技能分为**两大完全独立的轨道**：左侧/上部的主动战斗技能与下部的被动强身技能。

```text
+---------------------------------------------------------------------------------------+
|                                    技能界面 (CDlgSkill)                                |
+---------------------------------------------------------------------------------------+
|  [武将选择栏]  |                    [技能列表区]                    |  [技能详情与升级区] |
|   (RoleChoose) |                                                    | (PanelSkillDetail)|
|                |  【战斗技能】(listFightSkill)                      |                   |
|   主角 (混混)   |  - 出战技能需在角色面板右侧装配 (TextId 400303)      | - 技能名称与等级   |
|   武将1 (攻将)  |  - 主动触发 / 气力释放 / 绝招大招                    |   (360021: 等级X/Y)|
|   武将2 (阉派)  |                                                    | - 前置等级需求    |
|                |  【强身技能】(listStrengSkill)                     | - 技能威力与MP消耗|
|                |  - 升级直接永久提升角色四维属性 (TextId 400306)     | - 升级消耗战功    |
|                |  - 生命 / 物攻 / 魔攻 / 物防 / 魔防 / 速度 / 暴击   | - [大招升级符]勾选 |
|                |                                                    | - [升 级] 按钮    |
|                |  [洗战功] (单洗技能)    [一键全洗] (全技能重置)      |                   |
|                |  注: 【暗界波】等特殊新手技能不会被洗 (TextId 400309) | - 我的战功总额    |
+---------------------------------------------------------------------------------------+
```

### 3.1 战斗技能 (Fight Skills - 主动技能)
* **定位**：九宫格回合制战斗中根据角色气力（MP）与出手时机主动释放的绝技招式；
* **出战装配机制**：角色面板右侧设有 3 个出战技能槽位，玩家可从已学战斗技能列表中自由挑选装配；
* **核心属性与作用目标**：
  - 单体爆发斩杀（如攻将主力输出技）；
  - 群体横扫与全屏法伤（如阉派群攻技）；
  - 团队加血回春与群体净化（如阉派治疗技）；
  - 嘲讽拉仇恨、护盾减伤与金钟罩（如防将肉盾技）；
* **视听表现**：官方配置了 34 套动作特效与专属音效（`SkillAction.csv`，涵盖 `m_ajb.ogg` 暗界波、`m_xxdf.ogg` 吸星大法、`m_jzz.ogg` 金钟罩、`m_yzd.ogg` 一指禅、`m_zcdf.ogg` 葵花自残大法等）。

### 3.2 强身技能 (Strength Skills - 被动属性技能)
* **定位**：习得并升级后**无需装配、无需释放，直接以面板属性常驻生效**；
* **覆盖属性维度**（对应 `member_shuxing`）：
  - **强身·健体**：永久按固定值与百分比大幅提升生命上限（`Blood`/HP）；
  - **强身·蓄力**：提升物理攻击力（`PhyAtk`）与法术攻击力（`MagAtk`）；
  - **强身·金刚**：提升物理防御（`PhyDef`）与法术防御（`MagDef`）；
  - **强身·神速**：提升出手速度（`Speed`，决定回合制出手绝对先后顺序）；
  - **强身·精准/狂暴**：提升命中率、暴击率与格挡率。

## 五、 技能等级成长与升级计算规范

### 4.1 等级规则与上限
1. **技能当前等级 (`level`) 与上限 (`max_level`)**：
   * 格式严格遵循官方规范 `strres.ini` 条目 `360021`：`技能等级: %d/%d`；
   * **角色等级压制限制 (`require_level`)**：技能等级上限直接受限于武将当前角色等级（如角色 15 级，技能最高提升至 15 级）；
   * 达到上限时，状态标记 `is_full = 1`，升级按钮置灰并提示已满级。

2. **技能威力成长公式**：
   $$	ext{实时技能威力/属性} = 	ext{howmuch} + (	ext{level} - 1) 	imes 	ext{up\_base} 	imes (1 + 	ext{level} 	imes 	ext{up\_i})$$
   * `howmuch`：1 级技能基础数值（伤害底数、回血量或属性点）；
   * `up_base`：每升 1 级技能获得的绝对基础增量；
   * `up_i`：高阶技能等级的成长系数加成；
   * 持续状态回合公式：$$	ext{持续回合} = 	ext{turn} + (	ext{level} - 1) 	imes 	ext{turn\_up}$$。

### 4.2 升级消耗核心：【战功】体系
1. **战功消耗计算**：
   * 每次升级技能主要且唯一消耗游戏核心资源——**【战功】(Merit)**；
   * 升级消耗战功公式：$$	ext{消耗战功} = 	ext{upd\_cost\_base} 	imes (1 + 	ext{level} 	imes 	ext{upd\_cost\_time})$$；
2. **特殊升级道具与辅助**：
   * **元宝代偿 (`chkYuanBao`)**：若战功不足，允许勾选元宝直接补齐差额；
   * **大招升级符 (`chkDaZhaoFu`, TextId: `400312`)**：高阶绝技突破时可消耗专属符箓减免大量战功。

### 4.3 官方战功四大经济产出途径 (`strres.ini` 361327)
1. **城外过关通道**：挑战各府副本通关结算必定掉落战功；
2. **PK中心擂台切磋**：与同城实力相近的玩家比武获胜获取战功；
3. **日常主线任务**：每日日常活跃任务空投大量战功；
4. **静修堂与关公祠**：帮会静修堂打坐修炼、主城关公处每日拜神领战功。

## 六、 洗战功与 100% 无损重置机制

为避免玩家加错技能或转职后战功沉没，官方提供了全套洗战功系统：

1. **单项技能洗点 (`btnClearOne`, TextId: `400307`)**：
   * 官方台词（`strres.ini` 条目 `360001`）：
     > *“花费 %d 元宝，把技能【%s】等级重置为 1 级，重置后返回 %d 战功”*
2. **全技能一键全洗 (`btnClearAll`, TextId: `400308`)**：
   * 官方台词（`strres.ini` 条目 `360002`）：
     > *“花费 %d 元宝，把所有技能等级重置为 1 级，重置后返回 %d 战功”*
3. **100% 战功全额返还铁律**（`strres.ini` 条目 `361346`）：
   > **“你可以将你伙伴身上的技能在技能训练界面重置为 1 级，将返还 100% 的战功给你。”**
4. **特殊保留技能保护 (`staClearSpec`, TextId: `400309`)**：
   * 规则：`【%s】不会被洗`（如混混初始技能【暗界波】、恶搞被动【厚脸皮】永久保留）。

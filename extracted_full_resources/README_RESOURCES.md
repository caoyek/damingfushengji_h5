# 🎮 《大明浮生记》商业级工程标准重构与开发指南

本项目为经典武侠手游《大明浮生记》（基于天晴数码 C3 引擎）的完整逆向解包、工程资产重构与服务端复刻框架。

---

## 📁 1. 工程目录结构说明

```text
daming_project/
├── docs/                         # 【设计与技术规范文档】
│   ├── GDD/                      # 策划设计方案（职业、战斗公式、装备、特色玩法）
│   ├── TDD/                      # 技术架构设计（C3引擎原理、JSON通信协议、CMsg接口）
│   └── DataDict/                 # 核心数据字典与 31 张数据表索引说明
├── client/                       # 【客户端工程与静态资产】
│   ├── assets/                   # 解包出的标准格式游戏资产
│   │   ├── images/               # 10,213 张游戏美术 PNG 贴图（按类别归档）
│   │   ├── audio/                # 游戏音频（bgm 背景音乐、sfx 基础音效、skill 技能音效）
│   │   ├── ui_layouts/           # 347 个标准 XML 界面布局文件
│   │   ├── animations/           # 13 个 ANI 动作序列文件
│   │   └── fonts/                # 游戏内置矢量中文字体 font.ttf
│   ├── configs/                  # 客户端启动配置（platformcfg.xml 等）
│   └── bin/                      # 原始 APK 安装包与手机数据备份
├── server/                       # 【服务端与单机模拟器框架】
│   ├── data/                     # 全量 31 张游戏核心数据表
│   │   ├── tables_json/          # JSON 格式数据表（程序直接加载）
│   │   └── tables_csv/           # CSV / Excel 格式数据表（策划编辑查看）
│   └── src/                      # 服务端开发脚手架源码
│       ├── core/                 # 网络网关与 HTTP/Socket 协议路由
│       ├── battle/               # 回合制战斗演算引擎与战报生成器
│       ├── dict/                 # 装备数值字典、武将成长字典、怪物掉落字典
│       └── logic/                # 玩法逻辑（角色/背包/强化/牢房/跑商/科举）
└── tools/                        # 【工具链与自动化脚本】
    └── scripts/                  # WDF 提取器、KFDB 解析器、资源分类工具
```

## 🚀 2. 核心系统开发速查

1. **职业与门派**：混混（刺客）、攻将（物理战士）、防将（肉盾坦克）、阉派（法系辅助）。
2. **武将品质成长率**：白（<=21）、绿（22~32）、蓝（33~42）、紫（43~52）、红（53~63）、金（>63，如朱元璋、袁崇焕、魏忠贤）。
3. **战斗演算**：速度决定先后手顺序，命中率判定、暴击（150%伤害）、格挡（减伤50%），服务端演算后生成战报下发。
4. **特色系统**：大牢奴役打工（129种工种）、跑商倒卖场（112种货物）、科举答题考状元、江湖通缉令。

## 🛠️ 3. 开发指引与如何上手

* **策划人员**：直接在 `docs/GDD/` 中查阅和调整数值，编辑 `server/data/tables_csv/` 下的各数据表。
* **客户端开发**：在 `client/assets/ui_layouts/` 中查阅 XML 界面，在 `client/assets/images/` 提取美术素材。
* **服务端开发**：根据 `docs/TDD/01_技术架构与网络通信协议.md`，在 `server/src/` 实现各 `CMsg` 接口的 JSON 响应，并调用 `server/src/battle/` 生成战斗播报。
